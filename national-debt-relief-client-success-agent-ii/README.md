# National Debt Relief Butterfly Bundle

This folder contains the complete interactive HTML playbook.

## Open it on your computer

1. Double-click `index.html`.
2. It should open in Chrome, Edge, or your default browser.
3. Test the accordion sections, email tabs, progress tracker, and checklists.

## Publish with GitHub Desktop

1. Open GitHub Desktop.
2. Choose **File > Add Local Repository**.
3. Select this folder.
4. Create the repository if prompted.
5. Commit all files.
6. Publish the repository to GitHub.
7. On GitHub.com, open **Settings > Pages**.
8. Choose **Deploy from a branch**.
9. Select **main** and **/(root)**.
10. Save and wait for the live URL.

## Main files

- `index.html` — all playbook content
- `styles.css` — ButterflyOS branding and layout
- `script.js` — accordions, tabs, and saved checklist progress

Checklist progress is stored in each user's browser using localStorage.
